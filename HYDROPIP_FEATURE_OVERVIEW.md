# HydroPip Feature Overview

## The Short Version

HydroPip helps people build and operate a commercial-quality hydroponic tower system from accessible, off-the-shelf parts. The proven four-tower design supports up to 160 planting pockets using a 275-gallon IBC reservoir, scheduled top feeding, and reusable perlite-vermiculite growing media. It avoids the return plumbing and recirculated runoff that make many small hydroponic systems harder to maintain.

Pip Buddy is the AI growing assistant built around the system. Pip can guide a first-time grower through the build, explain parts, answer crop and troubleshooting questions, review photos, and connect users to the correct supplies. Pip Pro adds a persistent grow notebook with saved system details, conversations, planning, calendars, seeds, grow logs, history, and support for other hydroponic systems.

The result is more than a build guide. HydroPip is a repeatable growing workflow: build the system, plant it, operate it with practical guidance, harvest, reuse the media, move suitable mature plants to raised beds, reset the towers, and grow again.

## What Makes HydroPip Different

- **A real working system.** The site uses actual build and harvest photography, not concept renders, to document a system that has already produced food successfully.
- **Commercial-quality capacity from common parts.** The standard four-tower build provides up to 160 planting pockets without requiring a proprietary tower kit.
- **Timed feed without return plumbing.** A large mixed reservoir feeds the towers in short scheduled cycles. Runoff does not return to the IBC.
- **Simple expansion.** A grower can begin with one tower and extend the main feed line as space and confidence grow.
- **Reusable growing media.** The 50/50 perlite and vermiculite blend can be recovered, cleaned, topped off, and reused between crops.
- **Fast turnover.** With materials ready, both the initial build and a complete 160-pocket crop turnover can be completed in a few focused hours.
- **Guidance that stays with the grow.** Pip combines the HydroPip knowledge base, the grower's saved profile, recent conversation context, and AI reasoning to provide relevant next steps.

## Pip Buddy

### Practical AI Help

- Answers natural-language questions instead of forcing users through a fixed menu.
- Keeps replies concise by default and expands when the user asks for detailed instructions.
- Uses the HydroPip knowledge base for build steps, parts, feeding, nutrients, troubleshooting, scheduling rules, and planting guidance.
- Uses AI reasoning when the question needs more than a deterministic rules answer.
- Maintains recent context so follow-up questions can refer to the current conversation.
- Uses a saved grow profile and project context for personalized answers when the member is signed in.
- Provides local rules-based answers when a reliable deterministic response is available or AI is disabled.

### HydroPip Build Help

- Guides tower layout and sizing.
- Explains the galvanized support pipe, planter stacks, IBC reservoir, circulation pump, feed pump, main hose, branch tubing, diffuser pieces, and end-of-line fittings.
- Helps with first feed timing, runoff observations, reservoir mixing, nutrients, pH, EC/TDS, media reuse, flushing, and troubleshooting.
- Can recommend the next build step based on where the user is stuck.
- Can provide the correct product or affiliate link when a part or supply is relevant.

### Crop And Plant Guidance

- Uses the member's USDA growing zone, location, growing area, sun or lighting, crops, system stage, and goals.
- References zone-based seasonal planting guidance instead of relying on daily weather for routine crop timing.
- Helps with crop selection, planting windows, pruning, harvest, succession planting, pests, symptoms, and plant-health questions.
- Can distinguish between advice for the HydroPip system and custom planning for another hydroponic system.

### Photo Guidance

- Accepts photos of builds, plants, roots, pests, plumbing, and equipment.
- Shows progress messages while Pip analyzes an image or researches a product.
- Saves useful advice with the active conversation when the member is signed in.
- Free members receive a limited number of complimentary HydroPip Build Checks.
- Ongoing crop, pest, equipment, and custom photo guidance is a Pip Pro benefit.

### Conversation Organization

- Saves conversations for signed-in members.
- Lets users create, rename, reopen, and continue topic-specific conversations.
- Pip Pro notebooks begin with useful conversation areas such as crop planning, maintenance, pests, troubleshooting, and system optimization.
- Conversations persist across desktop and phone so a grower can move between indoor planning and outdoor work.

## Pip Pro

Pip Pro is the persistent grow-management workspace. It is designed to help serious growers keep one system's details, plans, tasks, observations, and conversations together.

### Grow Notebooks

- Each notebook represents one grow or hydroponic system.
- Stores the grow name, USDA zone, city or ZIP code, system type, growing area, light, stage, planting date, tower count, plant sites, reservoir size, media, nutrients, pump schedule, crops, goals, and notes.
- Makes this profile available to Pip when answering questions.
- Supports HydroPip systems and custom hydroponic systems.
- Allows additional grow notebooks through the product's multi-grow structure.

### Customizable Notebook Tabs

- Profile
- Planner
- Calendar
- Seeds
- Grow Log
- History
- Track Build
- Ask Pip
- Beta feedback during the testing period
- Account
- Field Guide
- Arrange, which lets the user reorder the primary notebook tabs and saves the preference to the account

### Planner

- Creates planting, feeding, pruning, harvest, refill, nutrient, and maintenance tasks.
- Includes repeat options and due dates.
- Preloads practical starter tasks so a new workspace is not empty.
- Allows users to add, edit, complete, and remove tasks.
- Gives Pip the ability to prepare schedule changes from a conversation for user review.

### Calendar

- Converts saved planner tasks into agenda, day, week, month, and year views.
- Keeps grow and maintenance work inside Pip Pro rather than pushing the user into an external calendar.
- Highlights the next useful task without making the system feel like daily busywork.
- Supports grouped weekly and monthly maintenance planning.

### Seeds

- Uses the grow's saved USDA zone, location, and area type to estimate what can be planted now, started next, or held for a later window.
- Produces crop-specific sow dates, direct-sow or protected-start guidance, germination and first-harvest windows, and optional succession intervals.
- Tracks crop, variety, source, seeds on hand, sow date, status, seeds sown, sprouts, germination rate, and notes.
- Adds approved sowing, germination-check, harvest-review, and succession tasks directly to Planner and Calendar.
- Keeps seed timing explicitly educational: seed-packet directions, local weather, microclimate, and extension guidance can override a zone estimate.
- Supports editing and removal as inventory or planting plans change, with a restrained path to seed sources when restocking is actually needed.

### Grow Log

- Saves pH, EC/TDS, temperature, and grow notes.
- Keeps observations connected to the selected grow notebook.
- Gives Pip historical context for future troubleshooting and optimization.

### History

- Collects project activity, saved conversations, readings, notes, and completed work.
- Helps the grower remember what worked across crop cycles.
- Creates the foundation for later production comparisons and sensor-assisted optimization.

### Track Build Inside Pro

- Makes the parts and build checklist available as a notebook tab.
- Keeps construction progress close to the saved grow profile and Pip conversations.
- Provides straightforward navigation back into the Pro workspace.

### Account And Subscription Area

- Shows the current plan and account status.
- Provides routes for subscription checkout and account management.
- Supports changing payment details or canceling through the connected Wix billing experience.
- Keeps legal, privacy, cancellation, and data-management information accessible.

### Invite And Sharing

- Provides an invitation link and QR code for easy sharing.
- Supports native sharing where available, plus copy-link fallbacks.
- Creates the foundation for a future referral and rewards program without requiring that system at launch.
