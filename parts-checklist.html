The current HydroPip support is 1/2 inch Schedule 40 PVC pipe with a 3/4 inch PVC tee used as an intentionally loose, removable top hose guide. It should pop off easily when flipping/resetting pots for the next crop, so it is not meant to be a glued pressure fitting. Pipe, tees, and cinder blocks are usually better bought locally. Used IBC totes should only be selected if prior contents were food-safe or non-hazardous and the tote is thoroughly cleaned.
