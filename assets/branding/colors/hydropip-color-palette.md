# HydroPip Color Palette

These values reflect the current live product interface and provide a starting point for web, app, social, and presentation work.

| Name | Hex | Primary Use |
| --- | --- | --- |
| Ink | `#13211D` | Headlines, primary text, dark graphic fields |
| Deep Green | `#0F4F37` | Strong backgrounds, chat bubbles, contrast panels |
| Leaf Green | `#1F7A4F` | Primary buttons, active states, links, success |
| Muted Green | `#52645E` | Secondary text and supporting labels |
| Sprout | `#CFE8A5` | Growth accents and soft highlights |
| Water | `#BFE4EE` | Water, information, and Grow Log accents |
| Amber | `#F1B84F` | Planner, reminders, calls for attention |
| Paper | `#F7F5EF` | Warm neutral page background |
| Soft Mint | `#EAF3ED` | Quiet section backgrounds and controls |
| White | `#FFFFFF` | Notebook pages, cards, and clean space |

## Use

- Keep Ink or Deep Green as the anchor so the brand does not become a one-note light-green palette.
- Use Leaf Green for primary actions; do not use several different greens for competing CTAs.
- Use Amber sparingly for planning, reminders, or one moment of emphasis.
- Use Water for logs and information, not for primary sales buttons.
- Confirm WCAG contrast for all text and interactive controls.
