# Branding

- `logos`: HydroPip wordmarks, lockups, and vector masters
- `mascot`: approved Pip full-body, head, pose, and expression artwork
- `colors`: palette swatches and digital/print color values
- `typography`: font licenses, files, and usage notes
- `guidelines`: brand guide, clear-space rules, voice, and approved examples

The two existing transparent Pip images remain at this folder's root because the live site currently references those paths.
