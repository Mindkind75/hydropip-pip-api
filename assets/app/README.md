# App Assets

- `shared`: artwork used by both app tiers
- `ios`: Apple-specific production assets
- `android`: Google-specific production assets
- `store-listing`: descriptions, feature graphics, privacy links, and review notes
- `screenshots`: clean and captioned store screenshots
- `notifications`: approved notification icons, copy, and artwork

Existing icon files remain in `../app-icons` because the live manifests use those paths.
