# Affiliate Assets

- `product-images`: approved product imagery or screenshots permitted by the program
- `link-sheets`: canonical links, ASINs, categories, quantities, and availability review dates
- `disclosures`: current Amazon and other partner disclosure copy
- `campaigns`: recurring nutrient, seed, media, meter, maintenance, and build promotions

Do not treat an Amazon order-history URL as a public product link. Record the last manual availability check for design-critical parts such as the center-hole stacking planters.
